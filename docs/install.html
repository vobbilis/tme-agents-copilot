Step 01

Bring access, not an editing skillset

You need permission to use the tools and the material. The director handles the technical preparation.

  • A Mac with Visual Studio Code and your organization's approved GitHub Copilot account.
  • Access to the private TME Agents repository. Ask its owner for access if GitHub returns a 404.
  • An internet connection for setup downloads, Copilot and separately approved speech generation.
  • An idea or source material you may use with Copilot. For a footage film, prepare approved local recordings.
  • Authorized local HPE Graphik assets for the branded film renderers. Font files and licenses are not included.

The guide pages use Fraunces and DM Mono web fonts from Google Fonts. If those requests are unavailable, the pages remain readable with browser fallback fonts. These web fonts are separate from the fonts used in your film.

Step 02

Get the kit and open the whole folder

  1. In VS Code, press Cmd+Shift+P and choose Git: Clone.
  2. Paste the repository address below, sign in if needed, and choose a local destination.
  3. Open the cloned tme-agents-copilot folder in VS Code.
  4. Approve workspace trust only if you trust the source and your policy permits it.
https://github.com/vobbilis/tme-agents-copilot.git

Alternatively, use Code > Download ZIP on GitHub, extract it and open the extracted folder. A sender-provided kit ZIP works the same way. Choose clone or download; you do not need to clone and then unpack another kit.

The folder you open must contain setup.command, START-HERE.md, .github/agents and tools/cmo-copilot. Do not open only a document or the tools subfolder. Finder hides the .github folder; that is expected.

Open the director

Open Copilot Chat and select cmo-chat-director from the agent picker. Only the director belongs in the picker; its specialists are intentionally hidden. No custom plugin installation or special slash command is needed.

Step 03

Let the director check the tools

Send this prompt, then stay in the same Chat. The director checks what your Mac actually has before proposing an installation.

Help me set up this kit. Check the local tools and explain anything missing.
Ask before downloading or installing anything. Do not generate narration,
artwork or video, or call specialist reviewers yet.

Setup checks Python 3.10+, Node 24+ with npm, and FFmpeg/ffprobe. With your permission it installs the kit-local speech, browser and rendering tools: Edge TTS, pypdf, Playwright/Chromium and Hyperframes, including their dependencies and install scripts.

Approve only the explained scope. System changes need separate permission and an existing approved Homebrew installation or help from IT. The kit does not install Homebrew, disable security controls or infer permission from opening the folder.

The result to wait for

ready means the offline tool checks passed. tools_present is only an inventory, and setup_required means more setup is needed. Even ready does not verify speech-service access, a complete film, font rights or human acceptance.

You answer approval questions; the director runs the commands. A failed download or verification does not erase the brief. Keep the completed work and ask for an explanation of the failed phase.

Step 04

Bring the right font assets

The current branded renderers require HPE Graphik Regular, Medium and Bold. Obtain them through your approved team or licensing channel, then tell the director where the authorized asset folder lives.

my-film-assets/
  fonts/
    HPEGraphik-Regular.otf
    HPEGraphik-Medium.otf
    HPEGraphik-Bold.otf

This is the expected folder layout, not a download included in the repository. The director supplies the absolute asset path to the tools. Rendering stops if the required font assets are missing or invalid; it must not silently substitute another font.

The shared film frame includes the HPE header, chapter footer and reserved caption space. Using those assets does not create permission to redistribute the font files or publish your film outside its authorized channels.

Step 05

Make your first film

Use one prompt at a time. Replace the bracketed parts, answer the director's questions, and continue from the information already agreed.

Shape the story

Help me make a film about [topic] for [audience], about [duration] long.
My sources are at [local file paths], or I can describe the idea.
Ask which material you may read. Recommend a film form and propose a brief,
narration and visual plan for me to review. Ask before saving project files.

The packaged reader supports UTF-8 text and Markdown, ordinary unencrypted PowerPoint slide text, PDF page text and Word document body text. Speaker notes need separate approval. This is text reading, not visual interpretation of charts, scanning of documents or audio transcription.

Confirm the authoritative sources and the claims they support. You can start without source files; the director should propose creative defaults and identify what still needs confirmation rather than inventing product facts.

Produce the agreed story

Use the story and visual plan we agreed on. Explain the required narration,
artwork, rendering and specialist reviews, including their scope and any
estimated costs. Ask for the necessary permissions before running them.
Then give me the resulting cut to watch and listen to.

Edge TTS receives separately approved narration text. Local rendering uses the approved plan and assets. Installation approval does not authorize these operations, and the kit does not promise a fixed render time.

Ask for a change

At [timestamp or scene], change [what needs changing] to [what I want].
Keep the previous cut. Explain which steps need to run again and ask before
processing. Reuse unchanged work where the existing tools support it.

A revised cut needs its own review. Changed narration can require new speech and timing; a visual change may leave audio reusable but still require new artwork or a render.

Review and take delivery

Help me record my decision and actual watch/listen and privacy-review results
for this exact cut. If I accept it and the required reviews are complete,
ask permission to deliver the MP4 and captions to [local delivery folder].
Do not upload or publish anything.

Watch the film with sound and report what you actually reviewed. The director records acceptance against that cut and checks the local delivery files. The result includes the MP4, captions and the associated review and delivery records.

Come back later

Before leaving, ask the director to save a checkpoint and a handoff, with your permission. In a fresh director Chat, use:

Resume my film from [saved handoff path]. Ask before reading saved material.
Use the existing checkpoint, check for changed inputs, and tell me the next
unfinished step. Do not repeat completed processing or assume earlier approvals
apply to a changed cut.
When something stops

Keep the work. Name the problem.

What you seeWhat to do
Repository not foundCheck your GitHub account and repository access. The repository is private.
No Copilot ChatUse your organization's approved Copilot account and official extension, or ask IT.
No director in the pickerConfirm the whole kit folder is open. If the director remains missing, report it to the sender; do not install an unrelated plugin.
Setup cannot find its scriptTell the director to resolve the kit's absolute setup-script path for every terminal call, without relying on a previous working directory.
A download or check failsPreserve the completed files. Ask which phase failed and approve any retry separately. Do not delete environments or bypass workstation controls.
Missing font assetsSupply the approved local font folder. The kit cannot download a license or substitute the required fonts.
A request to write scripts or JSONAsk the director to operate the packaged tools. A missing capability should be explained, not replaced with an invented pipeline.

Clean-copy setup passed in a fresh Chat on the same Mac used for the local films. Another Mac and optional Swift OCR compilation remain unverified. The validation notes distinguish demonstrated work from remaining limits.
